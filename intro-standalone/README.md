# JUNG / PARK / 亭朴 인트로 (단독 버전)

본 사이트 index 페이지의 인트로 애니메이션만 떼어낸 보관용 사본입니다.
헤더, 하단 메뉴, Info 팝업, 다크모드 토글, 아카이브는 전부 빠지고
**`Scroll →` 안내와 SVG 글자만** 남아 있습니다.

## ※ 이 폴더의 목적

본 사이트가 **세로 슬라이드로 바뀌기 전의 "가로 슬라이드" 버전을 보존**하기 위한 것입니다.
상위 폴더(`../`)의 index는 이제 위아래로 넘어가지만, 여기서는 원래대로 좌우로 넘어갑니다.
따라서 상위 폴더의 `style.css` / `responsive.js`와는 슬라이드 방향이 의도적으로 다릅니다.

## 실행

빌드 없이 `index.html`을 브라우저로 열면 됩니다. 다만 재방문 판정에
`sessionStorage`를 쓰기 때문에, 로컬 서버로 여는 쪽이 원래 동작에 더 가깝습니다.

```bash
python3 -m http.server 8000
# http://localhost:8000/intro-standalone/
```

## 조작

| 동작 | 결과 |
|---|---|
| 휠 아래로 / 왼쪽으로 드래그 | JUNG → PARK → 亭朴 순으로 진행 |
| 휠 위로 / 오른쪽으로 드래그 | 이전 화면으로 |
| 亭朴 화면 클릭 | 획 굵기 토글 (얇은 뼈대 ↔ 굵은 글자) |
| PARK 화면 클릭 | 글자 비율 토글 |

모바일(768px 이하)에서는 JUNG / PARK이 숨겨지고 亭朴만 세로로 길게 표시됩니다.

## 구성

```
index.html      Scroll 안내 + SVG 껍데기만
style.css       인트로에 필요한 규칙만 추려냄 (가로 슬라이드 유지)
reset.css       원본과 동일
responsive.js   가로 슬라이드 시절 원본과 거의 동일. 없어진 스킵 버튼 참조만 제거
```

`responsive.js`가 SVG path의 `d` 좌표를 화면 크기에 맞춰 전부 계산합니다.
글자 모양은 폰트가 아니라 이 계산식이 만들어냅니다.

## 다크 모드

토글 버튼은 없지만, 시스템 설정(`prefers-color-scheme`)을 따라갑니다.
본 사이트에서 다크로 켜둔 적이 있다면 그 설정(`localStorage`)도 그대로 따릅니다.
